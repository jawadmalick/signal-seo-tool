Run a complete site audit
Add your site URL and Signal runs a real Google Lighthouse scan (via the public PageSpeed Insights API, same engine as pagespeed.web.dev) for genuine SEO, Security, Performance, Mobile, and Accessibility scores — not estimates. It also checks live web search for off-page signals (mentions, social presence, brand visibility), since that can't be measured from the page itself. Paste the page's HTML too, optionally, to add keyword density, Open Graph/Twitter tags, and internal-linking checks that Lighthouse doesn't cover.
Running a live Lighthouse scan and searching the web — this can take 20–40 seconds…
Advanced: use your own PageSpeed API key (avoids rate limits)

Without a key, Google's shared free quota is small and can run out if this tool sees heavy use. Get a free key at Google Cloud Console (enable "PageSpeed Insights API" — no billing needed for this quota). Saved only in your browser.

Generative Engine Optimization (GEO)
Just add your site URL. Signal searches the web to gauge how citable and trustworthy the site looks to generative AI systems (ChatGPT, Perplexity, Google AI Overviews): citation/reference signal, content freshness, and E-E-A-T (Experience, Expertise, Authoritativeness, Trust) signals. There's no public API into any AI engine's actual citation logs, so this is a search-grounded proxy, not a direct read of what ChatGPT or Perplexity have indexed.
